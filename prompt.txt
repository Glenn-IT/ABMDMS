# Arduino PIR Motion Detection Monitoring System

## Complete Development Prompt for Claude Code

You are an expert Arduino, PHP, MySQL, XAMPP, and Web Dashboard developer.

I want you to help me build a **simple Arduino-based Motion Detection Monitoring System**.

The system will use:

* Arduino Uno
* HC-SR501 PIR Motion Sensor
* Breadboard
* Jumper/connecting wires
* USB cable
* Windows Laptop
* Arduino IDE
* XAMPP
* Apache
* MySQL
* PHP
* HTML
* CSS
* JavaScript

The purpose of the system is to detect motion using the PIR sensor connected to the Arduino Uno, send the motion detection event to the laptop through USB Serial communication, save the motion event into a MySQL database through a PHP application, and display the recorded motion events in a simple web dashboard.

---

# 1. SYSTEM ARCHITECTURE

Use this architecture:

Arduino Uno
↓
HC-SR501 PIR Sensor
↓
Arduino USB Serial Connection
↓
Laptop COM Port
↓
Serial Reader / Bridge Application
↓
PHP API
↓
MySQL Database
↓
PHP Web Dashboard

The system should work locally using XAMPP.

The final system should allow the user to:

1. Turn on the Arduino.
2. PIR sensor detects movement.
3. Arduino detects the motion.
4. Arduino sends a serial message through USB.
5. A local serial reader receives the message.
6. The serial reader sends the motion event to the PHP API.
7. PHP saves the event into MySQL.
8. The dashboard displays the new motion event.
9. The dashboard shows motion statistics and history.

# 3. ARDUINO PROGRAM

Create an Arduino sketch named:

motion_sensor.ino

The Arduino program should:

1. Initialize Serial communication.
2. Use Digital Pin 2 as PIR input.
3. Detect when motion starts.
4. Send a message through Serial when motion is detected.
5. Avoid sending hundreds of duplicate records while the same motion is continuously detected.
6. Detect when motion stops.
7. Send a clear serial message format.

Use a simple and reliable message format such as:

MOTION_DETECTED

and optionally:

MOTION_STOPPED

The Serial Monitor should show something similar to:

System Ready
Waiting for motion...
MOTION_DETECTED
MOTION_STOPPED

Add comments to the Arduino code explaining each section.

# 8. SERIAL COMMUNICATION

The Arduino Uno will be connected to the Windows laptop through USB.

The Arduino will appear as a COM port, such as:

COM3
COM4
COM5

Create a simple serial reader/bridge that:

1. Connects to the Arduino COM port.
2. Reads serial messages.
3. Detects:

MOTION_DETECTED

4. Sends the event to:

http://localhost/motion_monitoring/api/record_motion.php

The serial reader should prevent duplicate events.

Explain clearly how to identify the correct COM port using Arduino IDE.

If PHP cannot reliably access the Windows COM port directly, use a practical local bridge approach.

Prefer a simple solution that works reliably on Windows.

Possible approach:

Arduino
→ USB Serial
→ Python Serial Reader
→ PHP API
→ MySQL

If using Python as the serial bridge is more reliable than PHP, use Python.

If Python is used, create:

serial_reader.py

Use the pyserial library.

The Python script should:

1. Connect to the configured COM port.
2. Read Arduino serial messages.
3. Detect MOTION_DETECTED.
4. Send HTTP POST request to PHP API.
5. Print status messages.
6. Handle connection errors.
7. Automatically continue running.
8. Avoid duplicate motion records.

Create a configuration section where the user can easily change:

COM_PORT = "COM3"
BAUD_RATE = 9600
API_URL = "http://localhost/motion_monitoring/api/record_motion.php"
